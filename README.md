# Comandante de Prompt

Um jogo educativo para aprender sobre engenharia de prompt e melhorar suas habilidades de escrita de prompts.

![Comandante de Prompt](https://via.placeholder.com/600x300?text=Comandante+de+Prompt)

## Sobre o Jogo

"Comandante de Prompt" é um jogo interativo que desafia você a melhorar prompts fracos para diferentes cenários. O jogo é inspirado no "Guia de Prompting 101" e ensina conceitos importantes de engenharia de prompt como:

- Definição clara de persona
- Especificação da tarefa
- Fornecimento de contexto adequado
- Definição de formato da resposta
- Inclusão de detalhes específicos
- Garantia de tamanho apropriado do prompt

## Como Jogar

1. Escolha uma zona de missão (categoria)
2. Leia o cenário apresentado e o prompt fraco
3. Reescreva o prompt para torná-lo mais eficaz
4. Submeta seu prompt melhorado para avaliação
5. Ganhe pontos e avance para o próximo desafio

## Executar Localmente

### Opção 1: Usando um servidor local

1. Clone este repositório:
   ```
   git clone https://github.com/seu-usuario/comandante-de-prompt.git
   ```

2. Navegue até o diretório do projeto:
   ```
   cd comandante-de-prompt
   ```

3. Inicie um servidor local. Você pode usar:
   
   Python 3:
   ```
   python -m http.server
   ```
   
   Python 2:
   ```
   python -m SimpleHTTPServer
   ```
   
   Node.js (com o pacote http-server):
   ```
   npx http-server
   ```

4. Abra um navegador e acesse `http://localhost:8000`

### Opção 2: Abrir diretamente no navegador

Simplesmente abra o arquivo `index.html` diretamente no seu navegador. Duplo clique no arquivo ou arraste-o para uma janela do navegador.
