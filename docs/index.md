# Configurando o GitHub Pages

Para hospedar o Comandante de Prompt usando GitHub Pages, siga estes passos:

1. Acesse as configurações do repositório no GitHub (Settings)
2. Na barra lateral, clique em "Pages"
3. Em "Source", selecione a branch "main"
4. Em "Folder", você tem duas opções:
   - Selecione "/ (root)" se quiser servir diretamente o index.html na raiz
   - Selecione "/docs" se quiser manter os arquivos do site em uma pasta separada (neste caso, mova o index.html para a pasta docs)
5. Clique em "Save"

GitHub Pages irá fornecer uma URL no formato: `https://seu-usuario.github.io/comandante-de-prompt/`

Após alguns minutos, seu site estará disponível nessa URL!
