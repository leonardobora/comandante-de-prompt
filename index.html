Como Jogar

Objetivo: Melhorar prompts fracos e aprender técnicas avançadas de prompt engineering para IA generativa.

Como funciona:

  1. Escolha uma zona de missão (cada uma com cenários diferentes)
  2. Leia o cenário apresentado e o prompt fraco
  3. Reescreva o prompt para torná-lo mais eficaz, seguindo as melhores práticas
  4. Receba feedback em tempo real sobre seu desempenho
  5. Ganhe pontos por cada elemento de prompt bem implementado

Elementos avaliados em cada prompt:

  • Persona: Definir um papel ou perspectiva (ex: "Como um gerente...", "Você é...", "Aja como...")
  • Tarefa: Incluir um verbo de ação claro (ex: "Resuma", "Liste", "Compare", "Analise")
  • Contexto: Fornecer detalhes de fundo suficientes (tópico, fontes, público-alvo)
  • Formato: Especificar o formato de saída desejado (ex: tabela, e-mail, lista)
  • Especificidade: Incluir restrições ou detalhes específicos (limite de palavras, tom)
  • Tamanho: Criar um prompt detalhado o suficiente (10+ palavras é melhor)

Dicas:

  • Quanto mais específico e detalhado for seu prompt, melhores resultados você obterá
  • Revise o feedback para entender como melhorar
  • Você pode até mesmo usar seu prompt aprimorado no Gemini após completar um desafio!
